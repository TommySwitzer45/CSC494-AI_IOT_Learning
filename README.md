# CSC494 — AI IoT Learning

Through the Dirt Bike Sensor Monitor project, I learned how to build a practical IoT system that combines hardware and software to solve a real-world problem. I gained hands-on experience selecting and integrating sensors for monitoring oil temperature and air-box pressure, connecting them to a microcontroller that collects reliable data.

## Topics Learned with AI

### Topic 1 — Sensor Interfacing & Calibration
How to connect physical sensors to a microcontroller, calibrate them, and mount them on a real dirt bike without permanent modification. See [Topic_1_Sensor_Interfacing](./Topic_1_Sensor_Interfacing) for full details.

### Topic 2 — Dashboard & BLE Communication
How to build a wireless mobile dashboard for live sensor data and alerts using Web Bluetooth. See [Topic_2_Dashboard](./Topic_2_Dashboard) for full details.
